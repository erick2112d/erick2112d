# Публикация в RuStore

## Что уже готово

- `android/` — приложение-оболочка: игра открывается во встроенном браузере (WebView) из файлов приложения,
  интернет не нужен. Полный экран, горизонтальная ориентация, кнопка «Назад» закрывает окна и открывает паузу,
  в паузе есть «Выйти». Название пакета: `ru.mayak.lastlight` (задаётся в `android/app/build.gradle`).
- `.github/workflows/android.yml` — сборка на GitHub при каждом изменении игры. Готовые файлы:
  вкладка **Actions** → последний запуск «Android (RuStore)» → блок **Artifacts** внизу страницы.
- `store/rustore/` — иконка 512×512 и скриншоты 1920×1080 для страницы приложения.

В приложении пока нет рекламы и покупок за рубли (их сервисы Яндекс Игр работают только на Яндексе).
Самоцветы падают в игре и тратятся во вкладке магазина «Товары».

## Подпись (один раз)

RuStore принимает только подписанные файлы, и все обновления должны быть подписаны тем же ключом.
Ключ хранится только у владельца и в секретах GitHub — в репозиторий он не попадает.

1. GitHub → репозиторий → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**.
2. Секрет `LL_KEYSTORE_BASE64` — всё содержимое файла `LL_KEYSTORE_BASE64.txt`.
3. Секрет `LL_KEYSTORE_PASSWORD` — содержимое файла `LL_KEYSTORE_PASSWORD.txt`.
4. Вкладка **Actions** → «Android (RuStore)» → **Run workflow** (или любое изменение в игре).
   В Artifacts появятся `app-release.apk` и `app-release.aab`.

Файл ключа `lastlight-release.jks` и пароль сохраните в надёжном месте (облако, флешка).
Если ключ потеряется, выпускать обновления этого приложения в RuStore будет нельзя.

## Загрузка в RuStore

1. Консоль RuStore → приложение → **Версии** → новая версия → загрузить `app-release.apk`.
2. Название пакета в консоли должно совпадать с `ru.mayak.lastlight`.
3. Медиафайлы — из `store/rustore/`, описание и возрастной рейтинг — в карточке приложения.
4. Отправить на модерацию.

Номер версии (versionCode) растёт сам с каждым запуском сборки, поэтому новые сборки загружаются как обновления.
