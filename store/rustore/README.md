# Публикация в RuStore и подключение доната

Инструкция по шагам: от сборки до живой игры в RuStore с покупкой самоцветов за рубли.
Пункты, помеченные ✅, уже сделаны.

## Что уже готово

- `android/` — приложение-оболочка: игра открывается во встроенном браузере (WebView) из файлов приложения,
  интернет нужен только для покупок. Полный экран, горизонтальная ориентация, «Назад» закрывает окна и
  открывает паузу (там есть «Выйти»). Название пакета: `ru.mayak.lastlight`.
- Платежи RuStore (Pay SDK) встроены: цены берутся из консоли, покупка двухстадийная — деньги сначала
  замораживаются, игра выдаёт самоцветы и сохраняется, и только потом покупка подтверждается. Если игру закрыли
  посреди оплаты, оплаченная покупка выдаётся при следующем запуске. Одна покупка не выдаётся дважды.
- `.github/workflows/android.yml` — сборка на GitHub при каждом изменении игры.
- `store/rustore/` — иконка 512×512 и скриншоты 1920×1080.

---

## Часть 1. Ключ подписи ✅

RuStore принимает только подписанные файлы, и все обновления должны быть подписаны тем же ключом.

1. ✅ GitHub → репозиторий → **Settings** → **Secrets and variables** → **Actions** → вкладка **Secrets**:
   `LL_KEYSTORE_BASE64` и `LL_KEYSTORE_PASSWORD`.
2. Файл `lastlight-release.jks` и пароль храните в надёжном месте (облако + флешка).
   **Потеряете ключ — не сможете выпускать обновления этого приложения.**

## Часть 2. Карточка приложения в RuStore

1. Откройте [console.rustore.ru](https://console.rustore.ru) → **Приложения** → **Создать приложение**
   (или «Добавить приложение»).
2. Тип — **Игра**, название — **Последний Светоч**.
3. После создания посмотрите на адресную строку браузера:
   `https://console.rustore.ru/apps/1234567/...` — число после `apps/` это **ID приложения**. Запишите его,
   оно нужно для доната (часть 4).
4. Заполните карточку:
   - **Иконка** — `store/rustore/icon-512.png`.
   - **Скриншоты** — `screen-1-base.jpg` … `screen-5-forge.jpg` (горизонтальные 1920×1080).
   - **Категория** — Игры → Стратегии (или «Казуальные»).
   - **Возрастной рейтинг** — 12+ (фэнтезийные сражения без крови).
   - **Короткое описание** (до 80 символов), например:
     «Защити последний огонь мира: строй базу, куй оружие и отражай волны тварей».
   - **Полное описание** — можно взять первые абзацы из корневого `README.md` («Что есть в игре»).
   - Отметьте, что в приложении **есть платный контент / покупки** (если включаете донат).
   - Если консоль просит ссылку на **политику конфиденциальности** — игра не собирает личные данные,
     но ссылка всё равно может понадобиться: подойдёт страница с коротким текстом
     «Игра не собирает и не передаёт персональные данные; платежи обрабатывает RuStore».

## Часть 3. Сборка и загрузка версии

1. GitHub → вкладка **Actions** → слева «Android (RuStore)» → верхний запуск с зелёной галочкой.
   (Новый запуск: кнопка **Run workflow** справа → **Run workflow**.)
2. Внизу страницы, блок **Artifacts** → скачайте `last-light-android-N` (zip) и распакуйте.
3. Внутри: `apk/release/app-release.apk` и `bundle/release/app-release.aab`.
   - Проще загружать **APK** — он уже подписан вашим ключом, больше ничего не нужно.
   - AAB тоже можно, но тогда RuStore попросит загрузить ключ подписи (через утилиту PEPK) — это лишний шаг.
4. Консоль RuStore → приложение → **Версии** → **Создать версию** → загрузите `app-release.apk`.
   Название пакета подтянется из файла: `ru.mayak.lastlight`.
5. В поле «Что нового» — коротко про изменения. Отправьте на **модерацию**.
   Обычно проверка занимает от нескольких часов до 1–3 рабочих дней. После одобрения нажмите **Опубликовать**
   (если не выбрана автоматическая публикация).

Номер версии (versionCode) растёт сам с каждой сборкой, поэтому любая новая сборка загружается как обновление.

## Часть 4. Донат (покупка самоцветов за рубли)

### 4.1. Кто может принимать платежи

Платежи в RuStore подключаются для **ИП** и **юрлиц**. Самозанятым RuStore монетизацию сворачивает —
если вы самозанятый, нужно оформить ИП (можно на УСН 6 %, онлайн через Госуслуги или банк за 1–3 дня).
Аккаунт разработчика RuStore после этого переоформляется на ИП в разделе профиля / «Монетизация».

### 4.2. Подключение монетизации в консоли

1. Консоль RuStore → **Монетизация** (в меню слева или в профиле компании) → **Подключить**.
2. Заполните реквизиты (ИНН, расчётный счёт ИП/компании, адрес) и примите **оферту / договор** о приёме платежей.
3. Дождитесь проверки (статус в том же разделе). Пока она идёт, можно делать следующие шаги.

### 4.3. Товары — идентификаторы должны совпадать в точности

Консоль → приложение → **Монетизация** → **Покупки в приложении** (In-app) → **Создать** — для каждого товара:

| ID товара (ровно так) | Название | Тип | Что получает игрок | Цена (пример) |
|---|---|---|---|---|
| `gems_small` | Горсть самоцветов | Потребляемый | 100 самоцветов | 79 ₽ |
| `gems_medium` | Мешочек самоцветов | Потребляемый | 550 самоцветов | 299 ₽ |
| `gems_large` | Сундук самоцветов | Потребляемый | 1200 самоцветов | 599 ₽ |
| `starter_pack` | Набор основателя | Потребляемый | 300 самоцветов, 2000 монет, «Клинок Основателя» | 199 ₽ |

- Тип — **потребляемый (consumable)** для всех четырёх: «Набор основателя» игра сама показывает только один раз.
- Цены ставьте любые — игра покажет ту, что указана в консоли.
- Описание и картинка товара — на ваше усмотрение (можно взять иконки из игры).
- После создания товар нужно **активировать / опубликовать**, иначе SDK его не увидит.
- Товар, которого нет в консоли, в магазине приложения просто не появится.

### 4.4. Включить платежи в сборке

1. GitHub → **Settings** → **Secrets and variables** → **Actions** → вкладка **Variables** (не Secrets!) →
   **New repository variable**.
2. Name: `RUSTORE_APP_ID`, Value: ID приложения из части 2, шаг 3 (только цифры).
3. **Actions** → «Android (RuStore)» → **Run workflow**. В новой сборке платежи включены.
   (Без этой переменной сборка тоже работает, просто вкладка покупок за рубли скрыта.)

### 4.5. Проверка без настоящих денег

1. Консоль → **Монетизация** → **Тестовые платежи** (или «Тестировщики») → добавьте свой аккаунт RuStore.
2. На телефоне установите RuStore и войдите под этим аккаунтом.
3. Установите `app-release.apk` из новой сборки (файлом, через «Установить из неизвестных источников»).
4. Игра → кнопка **Магазин** → вкладка **Самоцветы**: видны товары с ценами в рублях.
5. Купите товар → откроется оплата RuStore → тестовая оплата → самоцветы появятся в игре.
6. Проверьте восстановление: начните покупку, оплатите и сразу закройте игру — при следующем запуске
   самоцветы должны прийти.

Если товары не появились: проверьте, что ID приложения в переменной верный, товары активированы,
монетизация подключена (не «на проверке»), и в сборке, установленной на телефоне, номер не меньше того, где
появилась переменная.

### 4.6. Выпуск версии с донатом

Загрузите новую сборку (часть 3) и отправьте на модерацию. В карточке приложения отметьте наличие
платного контента. После публикации деньги за покупки за вычетом комиссии RuStore приходят на счёт по графику
выплат из раздела «Монетизация» → «Финансы».
