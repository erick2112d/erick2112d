# Последний Светоч

HTML5-игра о строительстве и обороне базы для **Яндекс Игр**. Древние маяки погасли, мир затянул живой туман,
а Сердце Светоча — последний огонь в регионе. Хранитель рубит лес, строит оборону и отражает бесконечные волны тварей.

Движок не нужен: чистый JavaScript и Canvas, без внешних библиотек и загрузок из сети.
Персонажи, постройки и оружие нарисованы кодом в едином стиле: толстый контур, отдельные голова и тело, без рук и ног;
оружие парит рядом с персонажем.

## Запуск

```bash
npm start          # http://localhost:8080
npm test           # тесты симуляции (node --test)
npm run e2e        # сквозная проверка в браузере (Playwright), скриншоты в test-results/
npm run build      # архив для Яндекс Игр: dist/last-light.zip
```

## Управление

| Действие | ПК | Телефон |
|---|---|---|
| Движение | WASD / стрелки | джойстик (касание слева снизу) или касание земли |
| Оружие | 1 — посох, 2 — меч, 3 — лук | кнопки справа снизу |
| Авто/ручной бой | Q | кнопка «АВТО» |
| Атака вручную | клик по земле / Пробел (в сторону курсора) | касание земли |
| Стройка | карточка снизу → клик по освещённой земле, Esc — отмена | так же касаниями |
| Здание | клик: улучшение, приоритет энергии, выключение, резерв сырья | так же |

В режиме «АВТО» герой бьёт ближайшего врага в радиусе оружия, а если врагов нет — ближайшее дерево или камень рядом.

## Что есть в первой итерации

- Сердце Светоча, маленький участок света с деревьями, туман вокруг.
- Добыча древесины ударами по деревьям; деревья отрастают.
- Постройки: генератор, лесопилка, башня лучников, казарма мечников, дом ремонтников, стена; после маяка — каменоломня.
  Все здания улучшаются до 5-го уровня.
- Энергия: башни и мастерские работают, только если её хватает. Распределение по приоритету (настраивается в карточке),
  здание можно выключить; дефицит виден в HUD и значком над зданием.
- Цепочка производства: древесина → лесопилка (нужна энергия) → доски → башни и улучшения.
  Лесопилка не трогает резерв древесины (по умолчанию 10, меняется в карточке).
- Казарма сама выпускает мечников; враги в первую очередь бьют союзников.
- Враги: скелет, упырь-бегун, костяной латник (броня), скелет-лучник; босс Костяной Колосс каждые 10 волн.
  Выходят из тумана с 1–4 сторон; стороны видны до начала волны (панель и красные стрелки).
- Волны бесконечны: быстрые, обычные и длинные испытания; редкие события («Кровавая луна», «Густой туман»).
- Победа: золото, древесина, осколки света; поражение — Сердце выживает на 35 %, база не стирается, волну можно переиграть.
- После волны можно повторить её (полная награда) или идти дальше.
- Ремонтники выходят после волны и чинят постройки за древесину; стоимость ремонта видна в карточке.
- Северный маяк: открывается после 3-й волны, зажигается за доски и осколки, расширяет территорию,
  открывает лес, камни, каменоломню и запись в журнале.
- Сюжетные записи и журнал открытий.
- Сохранение в браузере (и в облаке Яндекса, если игра запущена там); загрузка после перезапуска.
- Yandex Games SDK: LoadingAPI.ready, GameplayAPI start/stop, межуровневая и наградная реклама, пауза звука
  при скрытой вкладке и рекламе. Вне Яндекса работает заглушка.

## Как менять игру без правки логики

Все числа — в [`src/config.js`](src/config.js):

- `BUILDINGS` — стоимость, прочность, энергия, рецепты, дальность и урон башен, отряды, ремонт, улучшения;
- `ENEMIES` — здоровье, скорость, урон, броня, награда, с какой волны появляются, «вес» в составе волны;
- `WEAPONS` — урон, перезарядка, дальность оружия героя;
- `WAVES` — рост силы волн, число сторон атаки, виды волн, награды, редкие события, частота боссов;
- `BEACONS` — маяки: где стоят, когда открываются, цена, радиус, что открывают;
- `STORY` — тексты сюжета;
- `SPRITE_OVERRIDES` — пути к своим PNG вместо нарисованных кодом персонажей (задел на будущее).

Новый вид врага = запись в `ENEMIES` + внешний вид в `LOOKS` ([`src/render/renderer.js`](src/render/renderer.js))
и палитра в `PALETTES` ([`src/render/art.js`](src/render/art.js)).

## Устройство кода

```
src/config.js          данные игры
src/core/              симуляция без DOM: можно гонять в Node (тесты, будущая арена)
  game.js              мир, постройки, энергия, производство, герой, бой, волны, ремонт, маяки, сохранение
  waves.js             генератор волн по номеру (детерминированный: повтор = тот же состав)
  energy.js            распределение энергии
  flowfield.js         поле пути врагов к Сердцу и A* для союзников
src/render/            отрисовка: art.js — рисунки, renderer.js — мир и анимации, fx.js — частицы
src/ui/                HUD, меню, карточки, окна
src/input.js           клавиатура, мышь, касания, джойстик
src/audio.js           синтезированный звук
src/platform.js        Yandex Games SDK и сохранения
tests/                 тесты симуляции и сквозной браузерный тест
```

## Публикация в Яндекс Играх

1. `npm run build` → `dist/last-light.zip`.
2. В консоли разработчика Яндекс Игр создать игру и загрузить архив (в корне архива — `index.html`).
3. Проверить в черновике: SDK подключается автоматически по адресу `/sdk.js`, реклама и облачные сохранения
   работают только там.
