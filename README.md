# Последний Светоч

HTML5-игра о строительстве и обороне базы для **Яндекс Игр**. Мир затянула живая Мгла, а Сердце Светоча —
последний огонь в регионе. Хранитель добывает ресурсы, строит и улучшает базу, куёт оружие и отражает бесконечные
волны тварей. Каждое улучшение Сердца раздвигает свет: на 100 уровне Мгла отступает со всей карты.

Движок не нужен: чистый JavaScript и Canvas, без внешних библиотек и загрузок из сети.
Персонажи, постройки и оружие нарисованы кодом в едином стиле: толстый контур, крупные головы, без рук и ног;
оружие парит рядом с персонажем.

## Запуск

```bash
npm start          # http://localhost:8080
npm test           # тесты симуляции (node --test)
npm run e2e        # сквозная проверка в браузере (Playwright), скриншоты в test-results/
npm run build      # архив для Яндекс Игр: dist/last-light.zip
npm run single     # вся игра одним HTML-файлом: dist/last-light.html
```

Параметры адреса: `?yandex` — принудительно грузить SDK Яндекса, `?testpay` — проверить покупки без Яндекса
(покупка проходит сразу).

## Что есть в игре

- **Сердце Светоча — 100 уровней.** Каждый уровень расширяет территорию и требует всё больше и всё более
  качественных ресурсов (дерево и камень → доски и кирпич → железо и уголь → кристаллы и серебро →
  мифрил и эссенция → звёздный металл). Уровень любой постройки не выше уровня Сердца.
- **Пять зон:** Последний приют, Ржавые холмы, Лунные пустоши, Мифриловые кряжи, Кратер Звезды —
  в каждой своя земля, свои ресурсы и сюжетная запись при открытии.
- **Мгла непроходима** для героя и союзников: тёмная зловещая область с клубами тумана, рунной кромкой,
  искрами и глазами во тьме.
- **15 материалов** в инвентаре; сверху на экране только монеты, самоцветы и еда.
- **31 постройка** в пяти разделах меню стройки (экономика, производство, оборона, армия, герой):
  лагерь рабочих (рабочие с топором и киркой сами добывают ресурсы), ферма, склад, генератор, рынок, дом
  ремонтников, лесопилка, каменоломня, камнерезня, углежогня, шахта, плавильня, мастерская; забор, ворота,
  шипы, башни лучников, баллиста, башни магов, огня и льда, сторожевая башня; казарма, стрельбище, святилище;
  кузня, оружейня луков, арканум, бронница, зал тренировок.
- **Эволюции** на 10, 20 и 30 уровне у 11 построек — по два варианта на выбор.
- **Цельный забор:** соприкасающиеся секции одного уровня сливаются визуально и делят общее здоровье
  (сломалась одна — сломался весь отрезок). Разные уровни или несоприкасающиеся отрезки считаются отдельно.
- **Оружие героя** (62 предмета): меч от деревянного до «Последнего Рассвета», булава (оглушение),
  парные кинжалы (крит, два удара), коса (вампиризм), алебарда (пронзающий выпад); луки и арбалеты;
  посохи огня, льда и молнии. Броня, амулеты, кольца. Инвентарь и три быстрых слота.
- **18 видов врагов**, открываются по мере прохождения: скелеты, псы, латники, лучники, щитоносцы, призраки,
  некроманты, чумные толстяки, тенекрылы, осадные големы, ведьмы, рыцари смерти, дракончики, пожиратели;
  4 босса по кругу каждые 10 волн.
- **Активности на карте:** сундуки, святилища с благословениями, разломы Мглы со стражами, записки сюжета,
  бродячий торговец каждые 5 волн.
- **26 достижений** с наградой в самоцветах, журнал сюжета.
- **Самоцветы (донат):** с волны выпадает 0–2 шт.; за них можно строить, улучшать и ковать без ресурсов
  (недостающее докупается), покупать ящики материалов; магазин с пакетами Яндекса и наградной рекламой.
- **Проходимая база:** у героя и союзников узкий контур столкновения с постройками и поиск пути по полуклеткам —
  между соседними зданиями можно протиснуться; герой за зданием просвечивает.
- **Звук без файлов:** все эффекты синтезируются при запуске (дерево, камень, тетива, металл, колокольчики, рог),
  со стерео по положению на экране; тихая музыка — ночной ветер и арфа между волнами, барабаны и лютня в бою
  ([`src/audio.js`](src/audio.js), [`src/audio-music.js`](src/audio-music.js)).
- Сохранение в браузере и в облаке Яндекса, лидерборд по волнам.

## Как менять игру без правки логики

Все числа и тексты — в [`src/data/`](src/data):

| Файл | Что внутри |
|---|---|
| `resources.js` | валюты, материалы, редкость |
| `world.js` | размер карты, Сердце (100 уровней, радиус, цены по диапазонам), залежи, зоны |
| `buildings.js` | постройки: цены, прочность, энергия, рецепты, урон, эволюции, порядок в меню |
| `items.js` | оружие и снаряжение, линейки крафта |
| `enemies.js` | враги и боссы: здоровье, скорость, урон, броня, добыча, с какой волны |
| `waves.js` | рост силы волн, виды волн, награды, события |
| `units.js` | герой, солдаты, рабочие, ремонтники |
| `activities.js` | сундуки, святилища, разломы, торговец, записки |
| `story.js` | сюжет |
| `achievements.js` | достижения |
| `shop.js` | товары за реальные деньги и за самоцветы, награда за рекламу |

Новый враг = запись в `enemies.js` + внешний вид в `LOOKS` и палитра в `PALETTES`
([`src/render/art/characters.js`](src/render/art/characters.js)).
Новая постройка = запись в `buildings.js` + рисунок в `ART` ([`src/render/art/buildings.js`](src/render/art/buildings.js)).

## Устройство кода

```
src/data/              данные игры
src/core/              симуляция без DOM (можно гонять в Node): мир, экономика, постройки, герой, бой,
                       юниты, активности, прогресс; flowfield.js — пути врагов и A* союзников
src/render/            renderer.js — мир и анимации, fx.js — частицы, art/ — рисунки кодом
src/ui/                HUD, окна, карточки, иконки
src/input.js           клавиатура, мышь, касания, джойстик
src/audio.js           синтезированные звуки, src/audio-music.js — фоновая музыка
src/platform.js        Yandex Games SDK: реклама, покупки, облачные сохранения, лидерборд
tests/                 тесты симуляции и сквозной браузерный тест
```

## Публикация в Яндекс Играх

1. `npm run build` → `dist/last-light.zip` (в корне архива — `index.html`).
2. В консоли разработчика создать игру и загрузить архив. SDK подключается сам по адресу `/sdk.js`.
3. **Покупки:** включить внутриигровые покупки и завести товары с идентификаторами
   `gems_small`, `gems_medium`, `gems_large`, `starter_pack` (цены задаются в консоли;
   цены в `shop.js` — только запасные подписи). Покупки расходуются сразу, неначисленные восстанавливаются при запуске.
4. **Лидерборд:** создать таблицу с техническим именем `waves` (число пройденных волн).
5. Реклама: межстраничная — после каждой второй волны; наградная — «×2 золота» за волну и +5 самоцветов
   (не чаще раза в 5 минут). Игра и звук ставятся на паузу на время рекламы и при скрытой вкладке.
6. Проверить черновик на ПК и телефоне: реклама, покупки, облако и лидерборд работают только внутри Яндекс Игр.
